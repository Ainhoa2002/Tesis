# Results tools — Guide

This single guide summarizes the result extraction and visualization tools included in the annex, how to use their export/configuration options, and where to find the canonical scripts.

Purpose
-------
- Describe the purpose and usage of the scripts that extract results, calculate impacts, normalize values, export data, and generate visualizations (including Sankey diagrams).

Where the canonical scripts live
-------------------------------
- Extraction & calculation: `TESIS/annex/LCI/results_tools/result_calculation_explained.py`
- Interactive visualization: `TESIS/annex/LCI/results_tools/visualize_results_interactive.py`
- Static plotting / impact comparisons: `TESIS/annex/LCI/results_tools/visualize_impact_results.py`
- Sankey generation & exports: `TESIS/annex/LCI/results_tools/sankey_visualizer.py`
- Sankey selector/CLI: `TESIS/annex/LCI/results_tools/sankey_interactive_selector.py`
- Batch Sankey generator: `TESIS/annex/LCI/results_tools/generate_all_sankey_diagrams.py`

Quick usage
-----------
1. Run extraction (dry-run to validate):

```powershell
python TESIS\annex\LCI\results_tools\result_calculation_explained.py --dry-run
```

2. Generate interactive comparison graphs:

```powershell
python TESIS\annex\LCI\results_tools\visualize_results_interactive.py
```

3. Generate Sankey HTML (single or batch):

```powershell
python TESIS\annex\LCI\results_tools\sankey_visualizer.py --input path/to/_sankey.json --output sankey.html
python TESIS\annex\LCI\results_tools\generate_all_sankey_diagrams.py
```

Export & configuration summary
------------------------------
- Export behavior is controlled inside `result_calculation_explained.py` and interactive visualization script.
- Key flags / variables:
  - `EXPORT_RESULT` (bool) — if True, results are copied to `EXPORT_RESULT_FOLDER` as well as local `LCI/RESULTS`.
  - `EXPORT_RESULT_FOLDER` (path) — default export location used in the original runs.
  - Visualization scripts prompt interactively to export graphs; accept default or supply a custom folder.

Normalization and Data Quality (DQ)
----------------------------------
- Normalization: optional; when enabled the impacts CSV files include `Amount (Normalized)` and `Normalized Unit` columns. Enable via `global_parameters.json` under `result_extraction.normalization.enabled`.
- Data Quality: optional extraction of process/exchange DQ (pedigree) into `*_data_quality.json`. Enable via `global_parameters.json` under `result_extraction.data_quality`.

Sankey notes
-----------
- Sankeys support two modes: flow-based and impact-based (configurable). They can be exported as interactive HTML (recommended) and optionally as PNG (requires `kaleido`).
- The notebook `sankey_visualization_guide.ipynb` contained examples and export snippets; the essential export code is included in `sankey_visualizer.py` and described above.

Module descriptions
-------------------
Describe what each module does, its inputs, outputs, and common flags.

- `result_calculation_explained.py` — Result extraction & calculation
  - Purpose: run the result extraction pipeline that reads processed LCIA data, calculates impacts per product system and per LCIA method, and optionally computes normalization and data-quality reports.
  - Inputs: `global_parameters.json`, processed intermediate data in `LCI/` (component/process CSVs), optional openLCA IPC (for DQ extraction and method metadata).
  - Outputs: `{system}_{method}_impacts.csv`, `{system}_{method}_inventory.csv`, `{system}_{method}_data_quality.json` (if enabled), `{system}_{method}_sankey.json` (if enabled).
  - Key configuration: `EXPORT_RESULT` (bool), `EXPORT_RESULT_FOLDER` (path), `normalization.enabled`, `data_quality.*`, `sankey` settings.

- `visualize_results_interactive.py` — Interactive comparison
  - Purpose: terminal-driven interface to select impacts, product systems, and graph types; generates comparison graphs (relative, normalized, absolute).
  - Inputs: `*_impacts.csv` files generated by `result_calculation_explained.py`.
  - Outputs: PNG graphs (`RELATIVE_IMPACT_COMBINED.png`, `NORMALIZED_COMPARISON_COMBINED.png`, `ABSOLUTE_COMPARISON_{impact}.png`).
  - Behavior: prompts for export; can write to local `LCI/RESULTS` and/or user-specified export folder.

- `visualize_impact_results.py` — Static plotting utilities
  - Purpose: programmatic plotting helpers used by the interactive tool or for scripted runs; produces per-impact and combined figures.
  - Inputs / Outputs: same CSVs → PNGs; used when you want to call plotting logic from other scripts.

- `sankey_visualizer.py` — Create Sankey diagrams
  - Purpose: load `{system}_{method}_sankey.json` files and render interactive Sankey diagrams (Plotly). Supports saving as HTML (recommended) and static images (requires `kaleido`).
  - Inputs: `_sankey.json` produced by the extraction step.
  - Outputs: interactive HTML files and optional PNGs.

- `sankey_interactive_selector.py` — CLI selector for Sankeys
  - Purpose: present a simple menu to choose available `_sankey.json` files and export HTML/PNG output.
  - Typical use: quick exploration and exporting of Sankey diagrams without manual file paths.

- `generate_all_sankey_diagrams.py` — Batch generator
  - Purpose: iterate over all available `_sankey.json` files and produce HTML exports (useful for packaging or creating a gallery of diagrams).

End-to-end workflow
-------------------
Follow this sequence to reproduce results and visualizations from raw processed inputs:

1. Prepare environment and parameters
   - Ensure `global_parameters.json` lists the target `product_systems_result_analysis` and LCIA `lcia_methodology`.
   - Toggle `normalization.enabled` and `data_quality.*` as needed.

2. Run extraction and calculation
   - Run `result_calculation_explained.py` in dry-run first to validate.
   - This generates the canonical CSV and JSON artifacts used by downstream visualization tools.

3. Inspect CSV outputs
   - Confirm `{system}_{method}_impacts.csv` contains expected columns (`Amount (Raw)`, `Amount (Normalized)` when enabled).

4. Produce comparison graphs
   - Use `visualize_results_interactive.py` to generate combined comparison plots and export them if desired.

5. Create Sankey diagrams
   - If Sankey JSON artifacts were created, run `sankey_visualizer.py` or `generate_all_sankey_diagrams.py` to output interactive HTML files.

6. Export results
   - If `EXPORT_RESULT` is enabled, files are copied to `EXPORT_RESULT_FOLDER` in addition to local `LCI/RESULTS`.

Notes on configuration and reproducibility
----------------------------------------
- `global_parameters.json` is the single source of run-time parameters (systems to analyse, LCIA method, normalization and DQ switches, sankey settings).
- Re-run the extraction step after changing parameters to regenerate downstream CSV/JSON inputs for visualization.
- The visualization scripts expect the canonical CSV structure; missing normalized columns will skip normalized plots but will not break absolute/relative plots.

Troubleshooting
---------------
- Missing normalized columns: re-run `result_calculation_explained.py` with normalization enabled.
- Export permission errors: verify `EXPORT_RESULT_FOLDER` path and write permissions.
- Sankey PNG export failures: install `kaleido` (`pip install kaleido`).
